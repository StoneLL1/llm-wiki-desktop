**日期：** 2026-06-24  
**范围：** 启动页、全局桌面壳、Dashboard、Wiki、Chat、Graph、Agent、Import、Lint、Exports、Settings、右侧上下文栏、抽屉与弹窗。  
**设计依据：** `UI-Frontend-design/` 全目录、`SPEC/FRONTEND_GUIDELINES.md`、`SPEC/DESIGN.md`、`SPEC/APP_flow.md`。

## 1. 目标

本轮不重做产品风格，也不改变后端流程。目标是让现有 Codex 风格工作台达到一致、紧凑、可靠的桌面工具质量：中英文都不截字，窄窗口不出现页面级横向滚动，右侧栏可以收起或作为抽屉打开，重复与占位文案被清理，所有控件具备明确的焦点和可访问名称。

## 2. 审计结论

### 2.1 已确认的结构性问题

1. `AppShell` 使用 `min-w-[1120px]`，并把主区域固定为 `240px + 1fr + 320px`。真实 980px 渲染出现整页横向滚动、筛选按钮被截断和多重滚动条。
2. `navigationStore.rightPanelOpen` 已存在，但壳布局、右栏头部和窄窗抽屉都没有消费它。
3. 工作区页头同时展示标题、摘要和两个动作；各视图内部又有自己的标题和动作，形成重复层级，部分动作在浏览器模式只弹出“需要桌面应用”的提示。
4. 按钮体系分裂为 `Button`、`.btn`、`.settings-button` 和大量页面内 class。固定高度普遍存在，但缺少统一的 `white-space`、`min-width`、`shrink` 和工具栏换行策略。
5. 启动页右栏固定 360px，筛选区不换行；顶部的设置与帮助按钮没有实际入口，只制造“先打开项目”错误提示。
6. Chat、Exports、Lint、Settings、Wiki 内部都有固定宽度子栏；当全局右栏与左栏同时存在时，中心工作区在窄窗口快速失去可用宽度。
7. 默认右栏与 Chat 右栏展示多项只有 `—`、不可用说明或永久禁用按钮的占位内容，降低扫描效率。
8. `styles.css` 没有任何宽度断点，也没有 `prefers-reduced-motion`；`textarea` 不在全局焦点环规则中。
9. CSS 存在未定义的 `--font-reading` 和错误的 `--ring` 引用；动效 token 与设计源不一致；部分组件散落硬编码颜色或 `text-sm` / `text-xs`。
10. `WikiTree` 刷新按钮和 Wiki 收藏按钮缺少明确的 `aria-label`；部分弹窗没有 Escape、焦点循环或关闭后焦点恢复。

### 2.2 基线证据

- `npm run test`：27 个测试文件、130 个测试全部通过。
- `npm run lint`：通过，零 warning。
- `npm run build`：通过；存在既有的大 chunk warning，不属于本轮视觉缺陷范围。
- 中英文 locale 均为 947 个 key，无缺失或空值。

## 3. 设计方案

### 3.1 壳层与右栏状态

全局壳改为语义 class 驱动的三栏网格，取消 `1120px` 强制最小宽度。

- 宽窗口：左栏 240px、中心自适应、右栏 320px。
- 右栏收起：网格真正移除右栏列，中心区获得完整空间；工作区页头显示“打开上下文”图标按钮。
- `<=1180px`：右栏从网格移出，以固定抽屉覆盖在右侧；打开时显示遮罩，点击遮罩或按 Escape 关闭。
- `<=820px`：左栏自动收为 56px，只保留图标和 tooltip；最近页面区隐藏。
- `<=760px`：顶部品牌名、项目路径和常驻搜索输入逐步收紧；保留项目切换、搜索入口、任务、语言和设置。

右栏头部统一由一个共享组件渲染，标题左对齐，收起按钮右对齐，按钮具备 `aria-controls`、`aria-expanded`、tooltip 和 28px 点击区域。Dashboard、Wiki、Chat、Graph、Import、Agent 以及默认项目信息右栏使用同一行为。

启动页的最右信息栏也遵循同一原则：宽窗口可手动收起，窄窗口作为抽屉打开，避免再次出现固定 360px 挤压主区。

### 3.2 页头与文案减法

工作区只保留一个 52px 主页头：视图标题 + 右栏开关。删除全局页头中的点分隔摘要和重复的两枚动作按钮；真实动作继续由各视图自己的工具栏、快速操作或表单承载。

删除当前没有数据或没有行为的噪声：

- Chat 右栏中的空计时、空 token、永久禁用“标记问题”和只说明未实现的原始资料区。
- 默认右栏中的空“最近编译”和“磁盘占用不可用”。
- 启动页顶部没有实际功能的设置、帮助按钮。
- Settings 内容区重复的总标题与总描述；保留当前 section 的标题和描述。

保留安全说明、Git 检查点、密钥存储、破坏性操作确认等产品必要文案，不以“简洁”为理由删除风险信息。

### 3.3 控件与溢出规则

统一三套仍在使用的按钮入口：React `Button`、CSS `.btn`、`.settings-button`。

- 文字型按钮单行显示、按内容增长、默认不被 flex 压扁。
- 图标和文字都设置 `shrink-0`；需要占满面板的按钮允许容器控制宽度。
- 工具栏从固定 `height` 改为 `min-height + flex-wrap + padding-block`，窄窗口时动作换行，不裁字。
- 长路径、文件名和任务标题使用 `min-width: 0` + 单点截断，并保留完整 `title`。
- 多按钮弹窗底栏允许换行；高风险主动作始终位于最后。
- 仅图标控制必须有 `aria-label` 和 tooltip。

### 3.4 视图级适配

- Dashboard：健康行与快速操作在空间不足时换行；摘要网格保持最小可读列宽。
- Wiki：文件树在较窄窗口缩至 220px；正文与编辑工具栏不被挤出；冲突三栏在窄窗口转为纵向比较。
- Chat：会话栏缩至 220px；消息与 composer 保持可用最小宽度；工具条换行。
- Graph：搜索、颜色模式和重建按钮允许换行；画布浮层避免互相覆盖。
- Agent / Import：卡片网格与底部动作区换行；长 CLI 路径、来源路径可查完整值。
- Lint：详情栏在窄窗口降至 320px，并在更窄窗口改为上下布局。
- Exports：预览栏使用 `minmax(320px, 420px)`，空间不足时改为上下布局。
- Settings：左侧设置导航在窄窗口改为横向可滚动 section tabs；表单行从双列退化为单列。
- Launch：筛选 pill 可换行，右信息栏变抽屉，主区只保留一个垂直滚动容器。

### 3.5 可访问性与动效

新增可复用 modal focus hook：打开时记录触发元素，聚焦首个合理控件，Tab/Shift+Tab 保持在弹窗内，Escape 调用关闭，卸载时恢复焦点。应用到所有现有弹窗。

补齐：

- `textarea` 焦点环。
- 右栏抽屉的 `aria-modal`/label 与遮罩关闭行为。
- 图标按钮的可访问名称。
- `prefers-reduced-motion: reduce` 下关闭非必要 transition 和 blink animation。

### 3.6 Token 清理

`src/styles.css :root` 与设计源补齐 `--sp-16`、`--font-reading`、`--ring`、`--dur-slow`，并统一 `--ease`/`--dur-fast`。组件中的交互色、警告文字色和页面类型色改为语义 token；主题预览和图谱运行时颜色映射可以继续使用明确的功能色，但集中定义，不在 JSX 中散落。

## 4. 测试与验收

### 4.1 自动化

1. 右栏收起、重新打开、Escape 和遮罩关闭。
2. 切换视图后右栏开关仍可用，标题与 `aria` 状态正确。
3. 工作区页头不再出现摘要和重复动作。
4. 长中文/英文按钮遵守统一 class 契约。
5. 弹窗 Escape、Tab 循环和关闭后焦点恢复。
6. 启动页窄窗信息栏开关和无效占位按钮移除。
7. i18n key 对齐、无硬编码可见文案回归。

### 4.2 视觉矩阵

以 1440x900、1180x800、980x760、820x720 四档检查启动页和桌面壳；中英文、light/dark/auto 至少各覆盖一次。每个视图检查：

- 页面级横向滚动为零。
- 按钮文字完整，无重叠、无裁切。
- 工具栏、弹窗底栏和筛选项可换行。
- 右栏打开/收起后中心区尺寸正确。
- 每个区域只有预期的滚动容器。
- 键盘焦点可见，图标按钮名称可读。

## 5. 非目标与边界

- 不修改 `UI-Frontend-design/`、`src-tauri/gen/`、`wiki/wiki/`。
- 不改变 Tauri command、Rust service、数据模型或用户项目文件结构。
- 不新增视觉品牌、不引入新组件库、不制作营销式重设计。
- 不在本轮处理 Vite 大 chunk warning；它需要独立的按路由懒加载与打包性能任务。
