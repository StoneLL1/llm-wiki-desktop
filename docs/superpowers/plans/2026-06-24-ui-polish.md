> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变产品流程的前提下，修复所有现有前端界面的文字溢出、重复文案、右栏不可收起、窄窗横向滚动和可访问性不完整问题。

**Architecture:** 保留现有 React + Zustand 壳结构，用 `navigationStore` 作为右栏开关的唯一状态源；共享右栏头部、按钮契约和 modal focus hook，视图只负责自身内容。响应式由 `src/styles.css` 的语义 class 与设计稿断点统一控制，避免继续在 JSX 中堆叠互相冲突的固定宽度。

**Tech Stack:** React 19、TypeScript、Tailwind CSS v4、Zustand、react-i18next、Lucide React、Vitest、React Testing Library。

```tsx
interface RightPanelHeaderProps {

  panelId?: string;
}

export function RightPanelHeader({ title, panelId = "right-context-panel" }: RightPanelHeaderProps) {
  const { t } = useTranslation();
  const setRightPanelOpen = useNavigationStore((state) => state.setRightPanelOpen);
  return (
    <div className="right-panel__header">
      <span className="right-panel__title">{title}</span>
      <button
        type="button"
        className="icon-button"
        aria-label={t("shell.contextPanel.collapse")}
        aria-controls={panelId}
        onClick={() => setRightPanelOpen(false)}
        title={t("shell.contextPanel.collapse")}
      >
        <PanelRightClose aria-hidden="true" size={16} />
      </button>
    </div>
  );
}
```
