# ADR 0003: 按需下载程序，独立管理模型

- Status: Accepted
- Date: 2026-09-12
- Decision owner: product owner（本次对话确认）
- Supersedes: ADR 0002 的能力分发、重复完整性检查及逐路线安装自检要求；项目权限、取消、进程管理与失败恢复不变。

## 决策

所有可选外部程序都按需下载，不增加桌面安装包体积。应用已有的原生解析代码不因本次调整迁出。能力不是第三方插件市场，也不增加通用包管理器、依赖求解器或远程信任清单服务。

应用内置资源 catalog 固定官方程序归档的 SHA-256；下载位置可为维护者配置的任意 HTTPS 静态存储，资源自己的版本与桌面发布批次无关。GitHub Release 只是可选托管位置。资源上传或变更后匿名下载完整文件并检查大小/摘要；桌面发布预检只匿名读取小段内容，确认可达性、文件类型与声明大小（2026-09-14 发布简化），安装时仍完整检查 SHA；不再要求历史 GitHub Actions run、同版本 tag 或尚未公开的 Release 元数据作为使用前提。

新安装流程是：下载或选择文件 → 流式验证完整归档 → 安全解压 → 准备独立模型 → 一次运行时自检 → 原子注册所有路线。ZIP 来自可信 catalog 后无需第二套自定义 Ed25519 签名。安装器写入本地 `.installation.json`，记录归档和 manifest 摘要；此记录仅是应用管理目录的安装记录，不是面向恶意本机用户的防篡改系统。运行时读取 manifest、检查协议/平台/入口路径，正常调用不再读取整个程序/模型计算哈希。未带安装记录的旧包仍可使用旧签名读取路径，显式完整性诊断与构建检查仍可遍历 inventory。

平台约束用于程序本身的 OS/CPU 兼容；资源版本只表示实际程序版本和接口兼容性。完整路线质量验证属于资源构建检查，用户安装时只启动运行时一次。一次自检通过后，所有已知路线一起注册；更新失败保留此前版本。安装的 pending marker 在原子切换成功时清除；未提交安装在重启时恢复。

模型通过 catalog 可选 `modelFiles` 独立声明：相对 `models/` 路径、大小、SHA-256、候选 HTTPS URL。模型文件不进入平台程序 ZIP，多平台可共用同一份模型 URL。首次下载/离线导入检查 SHA，已安装缓存按普通应用数据复用，不重复重哈希。缓存与程序中的模型路径优先共享文件，不支持硬链接时复制；引擎保留现有模型路径和实际格式/加载检查，不引入新进程协议。旧完整 ZIP 继续可用。

离线用户选择程序 ZIP，独立模型放在同目录的 `models/<sha256>/<filename>`，也兼容原 `models/` 相对路径。离线安装绝不自动联网补模型。当前支持的是清单固定的官方模型；任意自定义模型架构/规格选择不在此次实现范围，不会隐式执行模型附带脚本。

## 来源与边界

参考 [同类应用源码对照](../../maintainers/capability-distribution-comparison-2026-09-12.md)：采用 Vibe/Buzz 的临时文件、安装时检查、就地模型读取和离线分发做法；借鉴 VS Code 的资源版本与 App 兼容性分离。不复制其整个扩展市场。

国内可达性需要实际维护的国内 HTTPS 源或离线分发。此变更没有虚构镜像、公开上传资源或修复已发 v0.2.1 二进制中的失效 URL。桌面 App 自身及 updater 签名保持原合同。
