# Optional capability packs for v0.2.1

These are optional OCR, transcription, document, browser, and media engines used by LLM Wiki Desktop. **Install the application from the [desktop release](https://github.com/StoneLL1/llm-wiki-desktop/releases/tag/app-v0.2.1).**

The app downloads the appropriate pack when you enable an import capability and verifies its signature and checksum before installation. You do not need to download these archives manually.

This supporting release is excluded from the desktop app's stable update channel. Licenses and component notices are included inside each pack; the catalog records platform support and download sizes. Build attestations and qualification reports are retained with the [release workflow](https://github.com/StoneLL1/llm-wiki-desktop/actions/workflows/desktop-release.yml).
