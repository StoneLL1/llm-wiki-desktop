# Settings Feature

Language, theme, Agent, provider, security, task, and update settings live here.

Startup behavior, the first creation parent, and creation-time template defaults
are fixed by the project-open specification rather than user-selectable
Settings: valid history opens the most recent project to Dashboard, otherwise
the no-project workbench is shown; the first parent is `Documents/LLM Wiki`
then the last successful parent; the creation template defaults to General and
cannot be switched after creation.
