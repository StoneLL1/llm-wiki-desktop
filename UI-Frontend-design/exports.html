Agent Memory Model
concept · 2026-06-19 · 1,284 字

Agent Memory 指代理在执行任务过程中保留、组织和唤起信息的能力。与一次性的 LLM 调用不同，Agent 需要在多轮交互、长时间任务和跨会话场景下保持对上下文的连贯理解。

主流实现可分为四类：短上下文窗口、长上下文检索、外部记忆系统、以及多模态记忆。
