### 01 Bye-Mac-App

这是一款基于SwiftUI开发的macOS原生轻量工具，主打一键批量关闭正在运行的应用程序，解决手动逐个退出软件的繁琐问题。

![Main UI look](https://mmbiz.qpic.cn/sz_mmbiz_png/9PQyIWQhAO1BMG1SBmm1pIHHic5DXBu6HZcLO2pgF93QW1T3oeW61jbn855ojxwHHg16MVFnOLhJ0zjOCHwWj0h8RvZWdBxshiaq1dtqfbkPo/640?wx_fmt=png&from=appmsg)

它界面采用玻璃拟态风格，适配浅色与深色模式，支持选择性保留需要运行的应用，空闲时几乎不占用CPU资源，使用体验贴近系统原生应用。

适合设计师、开发者等经常同时开启大量软件的用户，快速清理后台、释放系统资源，打造简洁清爽的工作环境。
```
    https://github.com/designsbymuzeer/Bye-Mac-App  
    
```

### 02 type4me

type4me是专为macOS打造的语音输入法，支持本地与云端双模式识别，准确率可以媲美云端付费工具，还支持流式识别边说边出字。

它自带文本润色、翻译、Prompt优化等处理功能，支持自定义热词与映射词，能有效校正专业名词识别误差，搭配专属Skill可实现接近百分百的识别准确率。

适合需要快速文字输入、频繁使用专业术语、追求高效办公的用户，也能满足语音转写、内容创作等场景的使用需求。
```
    https://github.com/joewongjc/type4me  
    
```

### 03 sidex

这是一个基于Tauri重构的VSCode工作台，将原本的Electron替换为系统原生Webview，大幅降低内存占用与安装体积，启动速度更快。

![SideX — VSCode workbench running on Tauri](https://mmbiz.qpic.cn/sz_mmbiz_jpg/9PQyIWQhAO0NBqUw4Rnw0cicGtYia90EIawibCptgRytKKyfsyRgLP5icVK1xDf5So5cEjCHSWz83YnSJFV70eztYfO0WUjsYV1j8jmFKVOVJ6I/640?wx_fmt=jpeg&from=appmsg)

它保留了VSCode完整的编辑、终端、Git集成、主题扩展等核心功能，支持从Open VSX安装插件，代码编辑与基础开发能力稳定可靠。

适合对内存占用敏感、想要轻量化开发环境的开发者，尤其适合低配Mac或需要长期开启编辑器的使用场景。
```
    https://github.com/Sidenai/sidex  
    
```

### 04 awesome-systematic-trading

这是一个系统化交易精选资源合集，覆盖量化交易所需的工具、策略、书籍、视频与课程，适合从零搭建量化学习与开发体系。

项目整理了97个量化开发库、40余种机构与学术研究策略、55本专业书籍，内容涵盖回测框架、交易接口、技术指标、机器学习应用等方向。

适合量化交易爱好者、金融开发者、投资研究者，无论是入门学习还是策略研发，都能找到对应的参考资源与实战工具。
```
    https://github.com/paperswithbacktest/awesome-systematic-trading  
    
```

### 05 developer-icons

developer-icons是面向开发者与设计师的高质量技术图标库，全部图标经过优化，支持自定义颜色、尺寸、描宽，适配各类开发与设计场景。

![Developer Icons](https://mmbiz.qpic.cn/sz_mmbiz_png/9PQyIWQhAO0ib7pbzGiciaMXOjA1q549RC7iaHbsJx5S6ZrIlILUJia2sBoMUYPd1y0WtOBspOOcYrSkZ44CqKjEVFcA4xz8qciceA4ojEhCV4IBw/640?wx_fmt=png&from=appmsg)

它完美兼容TypeScript，可直接在React、Next.js项目中以组件形式使用，也支持单独下载SVG文件，图标风格统一、可无限缩放不失真。

适合前端开发者、UI设计师、文档创作者，用于项目界面、演示文档、个人网站等场景的图标展示，提升视觉统一性与专业度。
```
    https://github.com/xandemon/developer-icons
```
