# Overleaf+Claude Code+本地LaTeX+GitHub写论文

**作者**: Lxxzzz_ | 👍 1842 | ⭐ 3017 收藏 | 💬 48 评论 | 📅 2026-04-08 | 📍 上海

核心就是把 Overleaf + Claude Code / Codex + 本地 LaTeX + GitHub 串起来，写论文真的会顺很多。

## 基础版流程

1. **先在 Overleaf 建好论文模板**
   前提是你有 Overleaf 会员。把论文模板建好之后，同步到 GitHub。

2. **本地 clone 论文仓库**
   在本地，比如 VSCode 里，把这个 repo clone 下来，同时提前配好本地 LaTeX 环境。

3. **开始用 CC / Codex 辅助写 paper**
   日常写作、修改、整理 rebuttal，都可以直接在本地完成，然后通过 git push 同步到 GitHub，再和 Overleaf 联动。

### 实用优点

- 🤝 **真的打通了多人协作和 AI 协作** — 导师、合作者、自己、AI 都可以围绕同一个仓库工作
- 🧾 **修改记录非常清晰** — GitHub 的版本管理对论文党太友好了
- 🛟 **能有效防止 Overleaf 意外翻车** — 同步到 GitHub 之后，妈妈再也不用担心论文丢了

## 进阶玩法

- ✨ **用 CC 和 Codex 反复 polish 论文** — 比如引言怎么改得更像顶会风格，实验怎么总结得更深入
- 🧠 **和 auto research 工作流结合** — 从 idea → 实验 → 记录 → 成文 整个流程都串起来

## 实用 Tips

- **Tip 1：尽量 writing from 文档** — 如果你有实验记录、周报、思路草稿、读论文笔记，拿这些去喂给 AI，再让它帮你整理成 paper 内容，质量通常会明显更高
- **Tip 2：就算现在没有文档，也可以先让 AI 帮你写文档** — 俄罗斯套娃式写作，但真的很好用
