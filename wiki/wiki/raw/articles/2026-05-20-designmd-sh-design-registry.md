# 一键获取Nike/SpaceX的设计风格？试试DESIGNMD.sh

**作者**: DracoVibeCoding | **公众号**: Draco正在VibeCoding

我最近关注前端比较多，之前写过了：

- [HTML-Anything](https://mp.weixin.qq.com/s/xxx)
- [Open-Slide](https://mp.weixin.qq.com/s/xxx)

今天又发现个帮你的 Agent 提供前端审美配色能力的 Registry site：DESIGNMD.sh

> https://designmd.sh/

怎么理解这个 Registry 呢？

它提供的是给 Agent 读取的设计说明文件 DESIGN.md（由于 Google Stitch 推而广之），包括：

- 配色
- 字体层级
- 间距、圆角、布局规则
- 组件风格
- 品牌/网站视觉分析
- 可用 `npx designmd.sh add <owner/repo>` 拉取到项目里

这些 DESIGN.md 可以用来指导 Agent 生成一致的 HTML / CSS / UI。

目前收录了二十多种 DESIGN.md（还在持续增长），全部都是知名品牌的设计和配色风格，21 种风格已可视化展示：

> https://hermes.aigc.green/designmd-demo/

如果你想使用哪个配色风格，直接把 "npx....." 对应的内容复制出来让你的 Agent 安装和使用即可～

Have fun～
