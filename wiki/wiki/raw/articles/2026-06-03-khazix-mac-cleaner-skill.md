# 为了不花那 120 刀，我把电脑清理软件做成了开源 skill

**作者**: 卡兹克 (@Khazix0918) | **来源**: X/Twitter

## 背景

作者看到一条推文，有人用 Codex 的提示词对 MacBook 做只读存储分析，发现了 116GB 的 `codex-tui.log` 文件和 500GB 的可回收空间。

出于好奇，作者对自己的 MacBook Air（积攒了 2 年的杂物）运行了同样的提示词，并加上「用中文回答」。Codex 发现了：

- **~100GB 的 B 站离线视频**，藏在 `Containers` 目录深处（下载了准备飞行时看但从来没看）
- Chrome、开发环境、Claude 等产生的大量文件

Codex 评估保守可释放约 **120GB**，激进方案可超 **140GB**。

## 创建开源 Skill

作者想把这个能力做成任何人都能用的工具，替代收费的 CleanMyMac（约 $40/年）。

- **开源仓库**: https://github.com/KKKKhazix/khazix-skills
- **触发词**: 「帮我看看存储」（任意自然语言请求均可）
- **跨平台**: 同时支持 macOS 和 Windows

## Skill 工作原理

### 1. 仪表盘概览
- 总容量、已用空间、可用空间，带颜色进度条
- 系统环境摘要

### 2. Top 5 空间杀手
- 按空间排序，含颜色标签、类型、完整路径、人话说明

### 3. 🟢🟡🔴 三色风险分级（核心）

**🟢 绿色 — 安全可清理**
- 纯缓存、临时文件、安装器残留，无功能影响
- 每项可展开：显示路径、需关闭的进程、清理命令
- 两个操作按钮：「移到废纸篓」（可恢复）或「直接删除」（不可逆），都需要确认弹窗
- 批量清理支持

**🟡 黄色 — 需人工判断**
- B 站视频、下载文件夹安装器、项目文件夹等
- Agent 解释是什么、为什么需要审查、删除有什么影响
- 无直接删除按钮，只有「在访达中打开」和针对已验证安全的子目录的「移到废纸篓」
- 例如：只删视频但保留 B 站登录状态

**🔴 红色 — 禁止触碰**
- 系统文件、活跃应用核心数据、sleepimage 等
- 解释为什么应该跳过
- 只有「在访达中打开」按钮，供高级用户自行处理

### 4. 长期优化建议
超越即时清理的可操作建议

### 安全原则
- 整个扫描为只读，无用户发起则不写入
- 删除始终需要两步确认（操作按钮 + 确认弹窗）
- AI 幻觉在此用例中极低，但仍建议谨慎

## 实测结果

- 从 MacBook Air 上清理了近 **120GB**
- 在同事的 Windows PC 上用 Codex 成功测试，同一 Skill 跨平台、跨 Agent 工具可用

## 与 CleanMyMac 对比

| 维度 | CleanMyMac | Agent Skill |
|------|-----------|-------------|
| 扫描时间 | ~30 分钟 | 几分钟 |
| 发现空间 | 15.8GB 通用垃圾 | 120GB+（含非传统冗余如 B 站视频） |
| 透明度 | 「用户缓存文件」等标签，无详情 | 完整路径、大小、说明、影响分析 |
| 可定制性 | 固定规则 | 理解自然语言，可按需查找特定类型文件 |
| 决策信心 | 用户必须盲信软件 | 颜色编码+描述赋能知情决策 |
| 灵活性 | 静态软件 | 可适配任何基于规则的任务 |

## 深层思考：Agent vs 传统软件

作者提出核心洞察：「软件正在从资产变成耗材。软件的本质就是人和机器之间的翻译层，而 Agent 正在填平这道鸿沟。」
