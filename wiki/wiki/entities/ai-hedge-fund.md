# AI Hedge Fund

## Overview

AI Hedge Fund（virattt/ai-hedge-fund）是一个完整的 AI 对冲基金团队模拟系统，用多 Agent 架构模拟真实投资决策流程。GitHub 一周涨星 4.7K，位列 Top 10。

GitHub: [virattt/ai-hedge-fund](https://github.com/virattt/ai-hedge-fund)

## Key Features

- **多 Agent 架构**：模拟真实对冲基金团队中不同角色（分析师、风险经理、交易员等）
- **完整决策流程**：从信息收集到交易决策的端到端模拟
- **开源可定制**：可自定义 Agent 角色和决策逻辑

## In the Ecosystem

AI Hedge Fund 是 [[multi-agent-collaboration]] 范式在金融领域的典型应用。多个 Agent 各司其职，通过分工协作完成复杂的投资决策任务。这与 [[finance-skills]]（提供金融分析 Agent Skill）和 Kronos（金融语言基础模型）形成互补——Kronos 提供语言理解能力，finance-skills 提供具体分析 Skill，而 AI Hedge Fund 展示了如何用 [[multi-agent-collaboration]] 架构将它们组织起来。
