# Finance Skills

## Overview

Finance Skills（himself65/finance-skills）是一套面向金融分析与投资交易场景的智能体技能工具集，遵循通用技能规范，可便捷对接各类 AI 助手使用。它是 [[skills]] 范式在金融领域的垂直应用。

GitHub: [himself65/finance-skills](http://github.com/himself65/finance-skills)

## Key Features

- **金融市场数据分析**：股票行情、财报数据、技术指标
- **社交平台舆情读取**：市场情绪分析
- **外部金融数据接口**：对接第三方金融数据 API
- **初创企业价值评估**：创业项目估值分析
- **通用 Skill 规范**：遵循 [[skills]] 标准，可接入 Claude Code 等 AI 编程助手

## Target Users

- 普通投资者：快速获取股票行情、市场情绪等关键信息
- 金融分析师：多维度金融信息处理，辅助投研分析
- 量化交易爱好者：策略研发辅助

## In the Ecosystem

Finance Skills 体现了 [[vertical-industry-agents]] 的设计理念——将通用 AI Agent 能力针对金融行业特定场景进行优化。它与 kronos（金融语言基础模型）和 ai-hedge-fund（多 Agent 对冲基金模拟）共同构成金融 AI 开源工具链。
