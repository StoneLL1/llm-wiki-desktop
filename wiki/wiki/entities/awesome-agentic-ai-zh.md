# awesome-agentic-ai-zh

## Overview

awesome-agentic-ai-zh 是一份开源的 AI Agent 中文学习路线图，从零学 AI Agent。三语对照（繁中、简中、英文），总时长预估 14-19 周。

开源地址：https://github.com/WenyuChiou/awesome-agentic-ai-zh

## 学习路径

### 7 个阶段

前三个阶段打基础：
1. Python 基础
2. LLM 基础
3. Prompt Engineering

之后分两条轨道：
- **Track A：CLI Power User** — 教你用现成的 Agent 工具提效
- **Track B：Agent Builder** — 从零造 Agent 一直到 Multi-Agent 编排

### 特色
- 每阶段配 1-5 个 mini project，附带成功标准
- 总共收录 145 个精选项目和资源
- 5 条按身份分流的延伸路线（研究员、开发者、老师、知识工作者、日常使用者）

## 与其他学习路线的对比
