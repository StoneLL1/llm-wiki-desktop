# Kronos

## Overview

Kronos 是由 **shiyu-coder** 开发的专为金融市场语言打造的基础模型。它针对金融领域的特殊语言模式进行了优化，适用于量化交易、行情分析、金融 NLP 等场景。在 GitHub 一周涨星 6.7K，位列 Top 10。

GitHub: [shiyu-coder/Kronos](https://github.com/shiyu-coder/Kronos)

## Key Features

- **金融语言专精**：针对金融术语、行情描述、研报语言等特殊表达进行优化
- **量化交易支持**：可作为量化策略研究和行情分析的基础模型
- **金融 NLP**：适用于金融舆情分析、研报理解、市场情绪判断等任务

## Context

Kronos 的出现标志着开源社区开始为垂直行业（尤其是金融）定制语言模型。这与 [[vertical-industry-agents]] 的趋势一致——将 AI 能力按具体行业需求优化。同时，它与 [[finance-skills]]（AI Agent 金融技能工具集）和 ai-hedge-fund（AI 对冲基金模拟）共同构成了金融 AI 开源生态。
