# SenseTime 商汤科技

## 概述

**SenseTime（商汤科技）** 是中国领先的人工智能公司，成立于 2014 年，专注于计算机视觉和深度学习技术。2026 年 6 月，商汤开源了 [[sensenova-skills|SenseNova-Skills]] AI 办公技能套件，标志着其向 AI Agent 生态的拓展——将自身 AI 能力以 [[skills|Skill]] 形式开放给 Agent 平台。

## AI Agent 生态参与

### SenseNova-Skills

商汤的 [[sensenova-skills]] 是一套面向 skills-compatible Agent 的开源办公技能套件，覆盖四大功能：信息图表生成、数据分析、PPT 创建、深度研究。兼容 [[openclaw|OpenClaw]] 和 [[hermes-agent|Hermes Agent]] 等主流 Agent 平台。

这是商汤从「提供 AI 模型/API」向「参与 Agent 生态建设」的战略延伸——将自身在视觉、多模态方向的积累封装为 Agent 可直接调用的 Skill 模块。
