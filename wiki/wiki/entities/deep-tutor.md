# DeepTutor

## 概述

DeepTutor 是香港大学 Data Intelligence Lab 开源的 AI 学习助手，目前 1.88 万 Star。提供多种学习模式，覆盖从知识获取到深度研究的完整学习链路。

## 核心特性

- **5 大学习模式**：
  - 聊天模式（RAG + 联网 + 代码执行）
  - Deep Solve（多 Agent 拆解复杂问题）
  - Quiz Generation（基于知识库自动出题）
  - Deep Research（并行 Agent 深度调研）
  - Math Animator（数学可视化）
- **TutorBot**：独立工作区和人设的自主 AI 助手，超越简单聊天机器人
- **Co-Writer**：AI 为第一公民的 Markdown 编辑器
- **Persistent Memory**：学习者画像在所有功能间共享

## 在 AI 教育生态中的定位

DeepTutor 是 [[multi-agent-collaboration]] 在教育领域的深度应用。它的 TutorBot 设计理念与 [[hermes-agent]] 的 SOUL.md 人设系统类似——赋予 Agent 独立身份和自主能力。
