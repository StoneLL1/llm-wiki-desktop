# 飞书（Feishu）

## 概述

飞书是字节跳动推出的企业协同办公平台，集成了即时通讯、日历、云文档、多维表格、视频会议等功能，是国内主流的企业级协作工具之一。

## 飞书 CLI 与 Agent 集成

飞书 CLI 是飞书推出的命令行工具，允许 AI Agent 通过终端直接操作飞书云空间、多维表格、文档等资源。这一能力将 AI Agent 与企业云平台打通，使 Agent 能够自动化处理日常办公任务。

## 5 个 Agent 办公玩法

1. **个人知识管理**：利用 Agent 自动整理飞书文档中的知识，构建个人知识库
2. **数据分析与决策**：Agent 通过飞书多维表格进行数据查询、分析和可视化，辅助业务决策
3. **文档协同编排**：多个 Agent 协同编写和编辑飞书文档，提升团队协作效率
4. **PPT 创建**：Agent 根据需求自动在飞书云空间生成演示文稿
5. **自动化工作流**：通过 CLI 工具将重复性办公操作自动化

## CLI 工具生态意义

飞书 CLI 代表了工具生态的重要趋势——将 AI Agent 与企业云平台打通，让 Agent 不仅能写代码，还能直接参与企业的日常办公流程。这种 CLI → Agent 的集成模式，为企业级 AI 应用提供了基础设施。
