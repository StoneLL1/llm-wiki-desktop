# claude-howto

## 概述

claude-howto 是一份全面的 [[claude-code]] 学习指南，覆盖从基础概念到高级 Agent 编排的全部内容。它填补了官方文档的空白——官方文档只说明功能是什么，但没教如何组合使用。目前 1.7 万 Star。

## 核心特性

- **10 个教程模块**：总学习时长 11-13 小时，从初级到高级渐进式
- **生产级模板**：大量可直接复制使用的生产级模板
- **可视化教程**：包含丰富的可视化教学材料
- **零门槛安装**：克隆下来把模板复制到项目目录即可使用
- **EPUB 导出**：支持生成电子书离线阅读
- **持续更新**：几乎与 Claude Code 版本同步更新

## 在 Claude Code 生态中的定位

claude-howto 是 [[claude-code]] 社区最重要的学习资源之一。与 [[oh-my-claudecode]] 的多 Agent 编排不同，claude-howto 侧重于教学和知识传递，帮助用户系统掌握 Claude Code 的完整能力。
