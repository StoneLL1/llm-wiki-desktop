# 科学研究 Skills 开源

## 概述

科学研究 Skills 是一组面向学术研究的开源 [[claude-code]] Skill 集合，覆盖从文献检索到论文写作的完整研究工作流。这些 Skill 体现了 [[skill-engineering]] 理念在科研领域的系统化应用。

## 核心 Skill 列表

### 文献检索
- 学术搜索引擎集成
- 引文网络分析
- 文献综述自动生成

### 数据分析
- [[stata-skill]] — 统计分析和计量经济学
- Python 数据分析工具集成
- R 语言分析支持

### 论文写作
- LaTeX 排版
- 参考文献管理
- 学术写作规范检查

### 实验管理
- 实验日志记录
- 结果追踪和复现
- 数据版本管理

## Computer Control Skill

GitHub 开源的 Computer Control Skill 是相关项目，允许 Agent 通过 [[computer-use-agent]] 能力控制计算机界面，可用于：
- 操作科研软件（SPSS、MATLAB 等）
- 从学术数据库采集数据
- 自动化实验流程
