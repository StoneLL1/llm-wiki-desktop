# Cursor

## Overview

Cursor is an AI-powered code editor and IDE that provides intelligent code completion, generation, and refactoring capabilities. It appears in 4 articles in the corpus and is frequently compared with [[claude-code]] as one of the primary tools for AI-assisted software development. Cursor represents the GUI-based approach to AI coding assistance, contrasting with Claude Code's CLI-first philosophy.

## Key Features

### AI-Powered Code Assistance
Cursor integrates AI directly into the editing experience:

- **Inline code completion**: Context-aware suggestions as you type
- **Code generation**: Generate functions, classes, and entire files from natural language descriptions
- **Code refactoring**: Intelligent refactoring with AI-guided transformations
- **Error detection**: Proactive identification of potential bugs and issues
- **Documentation generation**: Automatic code documentation

### IDE Integration
Cursor is built as a full-featured IDE (forked from VS Code), providing:

- File explorer and project management
- Integrated terminal
- Git version control
- Extension ecosystem compatibility
- Debugging tools

### Multi-Model Support
Cursor supports multiple AI models:

- Claude (Anthropic)
- GPT-4/4o (OpenAI)
- Other models via API integration

This flexibility allows users to choose the best model for their specific tasks.

## Cursor 四种模式（klöss 工作流）

1. **Ask mode** — 只读，AI 读取代码库回答问题，不改变任何东西。行动前思考
2. **Plan mode** — 编码前架构，创建详细实施计划，可视化图表
3. **Agent mode** — 主力，AI 自主写代码、编辑文件、运行终端。大多数氛围编程在这里
4. **Debug mode** — 结构化调试：运行时日志插桩、多假设验证、测试修复

工作流：Ask 理解 → Plan 架构 → Agent 构建 → Debug 修复
