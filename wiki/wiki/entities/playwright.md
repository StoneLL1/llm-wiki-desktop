# Playwright

## Overview

**Playwright** is Microsoft's open-source browser automation framework. It provides a unified API for Chromium, Firefox, and WebKit, and is widely used for end-to-end testing, web scraping, and browser automation.

## Role in AI Agent Ecosystem

Playwright is the foundational browser engine used by many AI agent browser tools, including [[browser-act]] and [[browser-use]]. However, it lacks built-in support for anti-detection, CAPTCHA solving, session management across multiple accounts, and human-in-the-loop assistance — gaps that specialized tools like BrowserAct address.
